# 🎲 MeepleHouse - Inventário de Board Games

Aplicação desenvolvida para gestão de acervo de jogos de tabuleiro, utilizando FastAPI (Python) no backend e HTML/Bootstrap 5 no frontend.

## 🚀 Como Executar o Projeto

Certifica-te de que tens o Python instalado no teu computador.

### 1. Instalar as Dependências
Abre o terminal na pasta do projeto e instala os pacotes necessários:

pip install -r requirements.txt

### 2. Iniciar o Servidor Backend (FastAPI)
Executa o seguinte comando para iniciar a API:

uvicorn main:app --reload

O servidor ficará ativo em: http://localhost:8000

### 3. Aceder à Aplicação
Abre o ficheiro index.html diretamente no teu navegador web. A interface ligar-se-á automaticamente à API local.
